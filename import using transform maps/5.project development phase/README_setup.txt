SKILL WALLET IMPORT DATA USING TRANSFORM MAPS

Project setup:
1. Use Skill_Wallet_Source_Data.csv as the sample source file.
2. In ServiceNow, create or select the appropriate Skill Wallet target table.
3. Import the CSV through Import Sets.
4. Confirm the Import Set Table contains the source rows.
5. Create a Transform Map from the Import Set Table to the target table.
6. Map the fields shown in the project documentation.
7. Use Skill ID as the matching/unique identifier where appropriate.
8. Run Transform.
9. Verify the target records and transform history.
10. Capture screenshots for the project demonstration.

Important:
- Field names may differ between ServiceNow instances.
- Select the actual target table/fields available in your instance.
- Do not use production data for testing.
